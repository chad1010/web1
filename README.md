# 인터넷 신문사 프로젝트

1인 인터넷 신문사 2개를 만드는 프로젝트. 각 매체는 독립된 Vite + React 앱이라 나중에 따로 배포하거나 저장소를 분리하기 쉽다.

| 폴더 | 매체 | 컨셉 |
|---|---|---|
| `insidecreator/` | **인사이드 크리에이터** | 인플루언서·크리에이터의 성장 과정과 수익 구조를 파고드는 인터뷰 전문 매체 |
| `moneypick/` | **머니픽 뉴스** | 재테크 앱·장비·도서 리뷰에 제휴링크(쿠팡파트너스 등)를 결합한 수익화 매체 |

## 실행 방법

```bash
cd insidecreator   # 또는 moneypick
npm install
npm run dev        # 개발 서버 (localhost:5173)
npm run build      # 배포용 빌드 → dist/
```

## 기사 올리는 법

- 인사이드 크리에이터: `insidecreator/src/data/articles.js` 배열 맨 앞에 기사 객체 추가
- 머니픽 뉴스: `moneypick/src/data/picks.js` 배열 맨 앞에 기사 객체 추가 (제휴링크는 `픽` 항목의 `링크` 값에 붙여넣기 — `"#"`이면 '링크 준비 중'으로 표시됨)

## 주의

- 현재 기사는 전부 사이트 구조 확인용 **샘플(가상 인물·미검증 리뷰)** — 정식 오픈 전에 실제 콘텐츠로 교체할 것
- 머니픽 뉴스의 제휴 고지 배너(`Disclosure.jsx`)는 표시광고법상 필수 — 제거 금지
- 창간 관련 조사 자료(등록 절차·수익화 모델·벤치마크)는 채미의 Brain 볼트 `0. Inbox/인터넷 신문사 자료조사.md` 참고
